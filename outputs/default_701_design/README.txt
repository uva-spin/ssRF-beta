Synchronized ideal-bin tensor design

Load rf_program.json (or .csv) in the existing pulse editor. All nonzero rows start at 0 and end at one common duration. U is an effective base rate, NOT calibrated watts.
Load starting_state.npz to reproduce the input population state and material kinetics.
Generating/loading the program does not run it. Press Start / restart program explicitly.
A different live state or material does not have the same prediction.
optimization_report.json contains search limits, convergence checks and no-RF comparison.
This is a finite bounded local search; no global optimum is certified.
